# 接力文档

## 当前目标

本轮只维护 `backend` 和 `leading`，不处理 `ixBrowser` 自动化工具。项目定位为跨境电商任务生命周期管理系统，面向后台运营、任务创建、申诉/治理跟进、反馈归档、财务结算和用户管理。

技术栈已经按管理系统方向收敛：

- 后端：Java 17 + Spring Boot 3.3.5 + Spring Data JPA + MySQL 8 + Flyway。
- 前端：Vue 3 + TypeScript + Element Plus + Vite。
- 图片：暂未接入图床，所有任务图、证据图、反馈图和国家图标先统一使用 `/test.jpg`。
- 国家：固定字典，美国排第一，后续不作为普通可维护数据。

## 新增通用任务模块

以下菜单现在统一走 `/api/task/*` 接口，并通过 `taskType` 区分业务：

| 菜单 | taskType | 编码前缀 |
| --- | --- | --- |
| VP 差评 | `vp_negative` | `VPN` |
| 反击成人 | `counter_adult` | `CA` |
| 反击拆变体 | `counter_split_variant` | `CSV` |
| 反击版权图片 | `counter_copyright_image` | `CCI` |
| 反击真实性投诉 | `counter_authenticity_complaint` | `CAC` |
| 反击真实性 VP 差评 | `counter_authenticity_vp_negative` | `CAV` |
| 反击商品安全投诉 | `counter_product_safety` | `CPS` |
| 反击变狗 | `counter_dog` | `CD` |
| 买家秀 | `buyer_show` | `BS` |
| 其他业务需求 | `other_business` | `OB` |

通用任务表字段覆盖：国家、ASIN、商品名称、商品链接、店铺、关键词、数量、优先级、问题类型、处理目标、申诉/处理说明、证据链接、证据图、渠道、状态、反馈链接、反馈图、备注。

## 后续建议

- 如果继续优化 UI，优先把直评和测评也逐步拆成更清晰的列表、详情、创建组件，但不要破坏已有业务流程。
- 当前通用任务页已经可跑通创建、列表、详情、状态流转、渠道录入、完成反馈、删除。
- 后续接入图床时，需要替换 `/test.jpg` 默认值，并补充上传接口和历史数据迁移脚本。
- 密码目前仍是明文/弱处理方向，正式环境建议接入 BCrypt 并准备历史密码迁移。
