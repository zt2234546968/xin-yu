# 启动与数据库迁移说明

## 环境要求

- JDK 17
- Maven 3.9+
- Node.js 20+
- MySQL 8+

## 后端配置

后端默认读取环境变量，也支持在 `backend/application-local.yml` 放本地覆盖配置。

常用变量：

```bash
SERVER_PORT=8080
DB_HOST=localhost
DB_PORT=3306
DB_NAME=xin_yu_db
DB_USERNAME=root
DB_PASSWORD=132321
```

启动：

```bash
cd backend
mvn spring-boot:run
```

## Flyway 迁移

迁移目录：

```text
backend/src/main/resources/db/migration
```

当前迁移：

```text
V1__init_xinyu_schema.sql
V2__fix_countries_and_placeholder_images.sql
V3__marketplace_task_modules.sql
```

表结构：

- `role`
- `country`
- `user`
- `invitation_code`
- `zhiping`
- `ceping`
- `order_list`
- `marketplace_task`

迁移说明：

- `V1` 创建基础角色、国家、用户、邀请码、直评、测评、订单表，并写入默认角色、默认国家、默认超级管理员。
- `V2` 增加 `country.sort_order`，固定国家顺序，美国第一，并把历史图片统一到 `/test.jpg`。
- `V3` 新增 `marketplace_task`，承载 VP 差评、反击类任务、买家秀和其他业务需求，并写入每个类型 1 条真实风格样例数据。

本地已验证数据库状态：

```sql
SELECT version, description, success
FROM flyway_schema_history
ORDER BY installed_rank;
```

应看到：

```text
1 init                                  1
2 fix countries and placeholder images  1
3 marketplace task modules              1
```

## 前端配置

前端默认请求 `/api`，开发环境由 Vite 代理到 `http://localhost:8080`。如需改接口地址，可设置：

```bash
VITE_API_BASE_URL=/api
```

当前未接图床，`leading/public/test.jpg` 是统一占位图。业务页面中的任务图片、证据图片、反馈截图、国家图标暂时引用 `/test.jpg`。

启动：

```bash
cd leading
npm install
npm run dev
```

构建：

```bash
cd leading
npm run build
```

构建产物 `leading/dist` 不作为源码维护，提交前应保持清理状态。
