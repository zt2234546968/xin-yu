# 项目分析与优化说明

## 项目范围

本次只分析和优化 `backend` 与 `leading` 两个项目。`ixBrowser` 属于自动化工具，暂不纳入前后端管理系统改造。

## 业务需求梳理

项目面向跨境电商任务管理，核心需求是管理用户、邀请码、固定国家字典、直评任务、测评任务和测评订单。管理端提供任务录入、任务状态维护、反馈信息维护、订单结算信息维护等操作入口，后端提供统一的 REST API。

## 当前已完成模块

- 认证与用户: 登录、注册、用户列表、资料编辑、密码修改。
- 权限基础: 角色创建、查询、更新、删除、默认角色和超级管理员初始化。
- 邀请码: 生成、校验、查询、列表、备注更新。
- 国家字典: 列表、详情、按名称查询、固定国家初始化。国家是系统固定字典，美国排序第一，业务上不开放新增、修改和删除。
- 任务中心: 直评任务、测评任务、多个反击业务页面和买家秀页面。
- 财务中心: 待结算订单、已结算订单。
- 测评订单: 创建订单、按测评任务查询订单、更新费用字段、软删除。

## 本轮优化内容

- 前端从 Vue 2 + Element UI + JavaScript 升级为 Vue 3 + TypeScript + Element Plus。
- 前端入口、路由、API 封装和主布局参考 `boss-chat-web` 重新整理。
- 前端旧语法已清理：`slot-scope`、`.sync` 和 `.native` 事件写法已改为 Vue 3 语法，`src` 下业务脚本已改为 TypeScript 文件。
- 前端全局样式统一了页面背景、表格表头、弹窗圆角和旧图标兼容展示，保证 Element Plus 下不出现空白图标。
- 前端保留现有业务页面，降低迁移风险。
- 后端 Spring Boot 升级到 3.3.5，并对齐参考项目中的 Flyway、MyBatis Plus 和 springdoc 版本习惯。
- 后端配置改为环境变量优先，支持 `application-local.yml` 本地覆盖。
- 新增 Flyway 初始迁移脚本，统一管理表结构和基础字典数据。
- 新增国家 `sort_order` 字段和固定国家迁移脚本，确保美国优先展示。
- 前后端图片暂时统一使用 `/test.jpg`，为后续接入图床预留替换点。
- 清理旧前端构建产物和临时日志，仓库只保留源码、配置、迁移脚本和必要静态资源。
- 新增项目 README 和开发文档，便于接力开发。

## 后续建议

- 将后端用户密码从明文改为 BCrypt 哈希，并补充密码迁移方案。
- 将 JPA Repository 与 MyBatis Plus Mapper 二选一收敛，避免双 ORM 长期并存。
- 为任务中心中大量重复页面抽取通用任务表格、任务详情抽屉和反馈弹窗组件。
- 为登录、任务创建、订单结算补充后端参数校验和前端表单规则。
- 接入正式图床或对象存储后，将前端上传占位逻辑和后端历史图片迁移统一替换为真实图片 URL。
- 将旧业务页面中的乱码文案逐步修复为 UTF-8 中文。
