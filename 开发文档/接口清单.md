# 接口清单

后端统一前缀为 `/api`，前端开发环境通过 Vite 代理转发到 `http://localhost:8080`。

## 用户

| 方法 | 地址 | 功能 |
| --- | --- | --- |
| POST | `/api/user/login` | 用户登录 |
| POST | `/api/user/register` | 用户注册 |
| GET | `/api/user/list` | 用户列表 |
| PUT | `/api/user/update` | 更新用户资料 |
| GET | `/api/user/info?id={id}` | 用户详情 |
| PUT | `/api/user/password` | 修改密码 |

## 邀请码

| 方法 | 地址 | 功能 |

## 国家

国家是固定字典，美国必须排第一。`create`、`update`、`delete` 保留兼容路由，但服务层会拒绝新增、修改和删除。

| 方法 | 地址 | 功能 |
| --- | --- | --- |
| GET | `/api/country/list` | 国家列表 |
| GET | `/api/country/getById?id={id}` | 国家详情 |
| GET | `/api/country/getByName?countryName={countryName}` | 按名称查询国家 |
| POST | `/api/country/init` | 初始化固定国家 |

## 通用任务

用于任务中心除直评、测评外的其他模块。通过 `taskType` 区分业务类型。

| 方法 | 地址 | 功能 |
| --- | --- | --- |
| GET | `/api/task/list?taskType={taskType}` | 指定类型任务列表 |
| GET | `/api/task/getById?id={id}` | 任务详情 |
| POST | `/api/task/create` | 创建任务 |
| PUT | `/api/task/update?id={id}` | 更新任务 |
| POST | `/api/task/updateStatus?id={id}&status={status}` | 更新任务状态 |
| POST | `/api/task/updateFeedback` | 更新渠道、反馈链接、反馈图片 |
| DELETE | `/api/task/delete?id={id}` | 软删除任务 |
| GET | `/api/task/generateCode?taskType={taskType}` | 按类型生成任务编号 |

支持的 `taskType`：

| taskType | 菜单 |
| --- | --- |
| `vp_negative` | VP 差评 |
| `counter_adult` | 反击成人 |
| `counter_split_variant` | 反击拆变体 |
| `counter_copyright_image` | 反击版权图片 |
| `counter_authenticity_complaint` | 反击真实性投诉 |
| `counter_authenticity_vp_negative` | 反击真实性 VP 差评 |
| `counter_product_safety` | 反击商品安全投诉 |
| `counter_dog` | 反击变狗 |
| `buyer_show` | 买家秀 |
| `other_business` | 其他业务需求 |
